Setup Guide

1. Đăng ký tài khoản Helios PLGrid:

Tạo account tại portal.plgrid.pl, xin grant access partition plgrid-gpu-gh200.

2. Generate SSH key trên VPS:

ssh-keygen -t ed25519 -f /opt/rfpose/.ssh/helios_ed25519 -N ""
ssh-copy-id -i /opt/rfpose/.ssh/helios_ed25519.pub YOUR_USER@login01.helios.cyfronet.pl

3. Cấu hình .env trên VPS:

HELIOS_USER=your_plgrid_username
HELIOS_SSH_KEY=/opt/rfpose/.ssh/helios_ed25519
HELIOS_ACCOUNT=your_grant_id-gpu-gh200
HELIOS_LOGIN=login01.helios.cyfronet.pl

# S3 endpoint reachable từ Helios compute nodes
S3_ENDPOINT_URL=http://207.180.243.242:9000
MLFLOW_TRACKING_URI=http://207.180.243.242:5000

4. Test connection: Bấm nút "Test Connection" ở trên.
